# L'Altro Spazio — Production Image Needs v1

**Date:** 16 August 2026
**Purpose:** Replace placeholder images in the page-experience prototype with real institutional material. Test whether ENCOUNTER arrives at page scale.
**Scope:** Image TYPES only — not a branding brief. Do not prescribe poses, do not request glossy photography, do not ask for generic bar images.

---

## Via Nazario Sauro

| Type | Why | Notes |
|------|-----|-------|
| Current exterior / arrival | First-contact orientation; visitor needs to recognise the building | Street-level, unposed |
| Current interior environment | Establishes the space as it actually is | Between events, not staged |
| Current human / social activity | The core ENCOUNTER moment — people working, interacting | Documentary, not promotional |
| Detail / object / process | One image showing a specific mechanism (counter, menu, workspace) | Chooses specificity over atmosphere |

## Parco 11 Settembre

| Type | Why | Notes |
|------|-----|-------|
| Current environment | Establishes the outdoor space as a real place | One wide, one detail if available |
| Current social / programme activity | Shows the summer programme in action | Concert, poetry night, or general gathering |

## Historical / Process

| Type | Why | Notes |
|------|-----|-------|
| Early Via Nazario (pre-2015 or construction) | One or two public-safe images if available | Establishes longitudinal depth; not required for first test |

## Access verification images

| Type | Why | Notes |
|------|-----|-------|
| Entrance | Practical orientation; helps visitor assess physical access before arriving | Street-level, clear |
| Threshold / door | Wheelchair / mobility access assessment | Width, step presence |
| Main circulation path | Internal navigation clarity | From entrance inward |
| Toilet | Wheelchair / mobility access assessment | If accessible and safe to photograph |

---

## What NOT to request

- Glossy branding photography
- Posed portraits
- Stock-style bar/cafe images
- Images of private individuals without consent
- Anything from social media without owner permission

## Purpose

Replace placeholders with real institutional material and test whether the creative direction's ENCOUNTER mechanism actually arrives at page scale with real photography.
