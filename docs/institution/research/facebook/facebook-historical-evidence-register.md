# Facebook Historical Evidence Register

**Working date:** 14 August 2026 (updated 14 August 2026, owner-correction pass)
**Purpose:** structured claim ledger for facts and observations derived specifically from the Facebook archive (2014-2025). This is a sub-register alongside (not a replacement for) the main `laltrospazio_evidence_register_v0.2.md`, using the same status vocabulary plus additional statuses introduced for this owner-correction pass: DOCUMENTED / ARCHIVE-SUPPORTED / CORROBORATED (TESTIMONY) / OWNER-CONFIRMED / OWNER-CONFIRMED APPROXIMATE / ATTRIBUTED / PROPOSED / INTERPRETATION / IMPLEMENTATION UNCERTAIN / HYPOTHESIS / UNRESOLVED / NOT ESTABLISHED / CONFLICTING / CONTRADICTED / INVALID INFERENCE / **CONFIDENTIAL SUPPORT** / DO-NOT-PUBLISH — plus an **archive-specific evidence-strength sub-classification**:

- **FB-A** — announcement + clear post-event/media corroboration
- **FB-B** — repeated contemporary posts/events across time
- **FB-C** — single explicit contemporary public post
- **FB-D** — interpretation from patterns across posts
- **FB-E** — hypothesis / research lead

**CONFIDENTIAL SUPPORT** is a new status introduced for this pass: it marks a claim as informed by internal, confidential material (owner-provided chronology/audit records, historical private correspondence, and formal proceedings records) that is **never quoted, copied, or reproduced** here. Where this label is used, only the safe historical conclusion (a date, an entity name, an operational fact) is recorded — no financial amounts, debts, creditor names, litigation strategy, bank/payment details, or personal contact information from that material appears anywhere in this file or any other file in this folder.

Claims are numbered **C-FB-01** onward to avoid collision with the main register's C001-C050. Claims C-FB-01 through C-FB-25 were established in the initial research pass; this update revises several of them in place (marked **[REVISED]**) and adds C-FB-26 onward for genuinely new claims arising from the owner-correction pass.

**Note on non-Facebook sources:** a separate file, `../origins-source-note.md`, ingests three owner-origin narrative documents (oral-history/editorial material, not Facebook posts). Its claims are numbered `C-ORIG-` to keep source provenance explicit and are cross-referenced from the relevant rows below (C-FB-01, C-FB-26) rather than merged into this Facebook-specific register.

## What this register does NOT do

- It does not resolve any of the UNRESOLVED items in the main `laltrospazio_evidence_register_v0.2.md` (current legal representative, current workforce composition, current accessibility audit, 2026 project funding outcomes) — the Facebook archive is silent on all of these by nature (it is a public-communications record, not a governance or HR record).
- It does not establish legal ownership, entity structure, or financial facts for any period from Facebook evidence alone — per the brief's explicit instruction and the working paper's own methodology. Where entity/ownership facts appear in this update (Associazione L'Altro Spazio; the two 50/50 SRL/SRLS structures), they come from owner testimony and confidential internal records, labelled accordingly (OWNER-CONFIRMED / CONFIDENTIAL SUPPORT), never from Facebook content itself.
- It does not treat any single post as proof of full delivery, outcome, or completion of an announced activity — per the brief's "invalid inference" warning (Working Paper v0.2 C049). Where a post describes a planned/announced event, that is stated as PROPOSED/announced unless independently corroborated (photos, press, repeated later reference).
- **It never reproduces confidential material.** Where internal, confidential sources (owner-provided chronology/audit records, historical private correspondence, formal proceedings records) informed a correction in this pass, only the safe historical conclusion is recorded, tagged CONFIDENTIAL SUPPORT. No financial amounts, debts, creditors, litigation strategy, bank/payment details, or personal contact information from those sources appears anywhere in this file, or in any other file in this folder.
