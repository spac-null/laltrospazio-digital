Current / Archive Marker

Same four real facts, three different systems for telling "this is happening now" apart from "this is history" — without giant labels, without color as the only signal, without archive turning sepia. Use the switcher above to test every treatment against all three palettes and all three type systems.

Treatment A — Temporal edge

Distinction carried by: border edge (solid vs. dashed), a small plain-language tag, and a metadata line — never by color alone. Works item-by-item, so it survives mixed lists (e.g. an event feed showing both a live and a historical entry together).

Treatment B — Density / framing

Distinction carried by: how much space and how much editorial voice each item is given. Current items are tight, dense, dated to today. Historical items get museum-label breathing room and the editorial typographic voice. Costs more space per item than Treatment A — better suited to a page that already separates current from historical content into its own region.

Treatment C — Sequence / grouping

Distinction carried entirely by section placement — one heading for "active now," one for "archive" — with no per-item marker at all. Cheapest to build and cleanest to read, but only works when a page can genuinely separate current from historical into two blocks; it has no answer for a single mixed list (see limitation below).
