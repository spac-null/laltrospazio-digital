Measure + Encounter — a rhythm/composition test

Studies 1–5 validated MEASURE (honest, dated, provisional facts) but under-tested ENCOUNTER: no image presence, no density gradient, no interruption, no coexistence of current and archival material. This is not a homepage design. It is one vertical sequence — quiet → dense → process → archival interruption → quiet — testing whether density, scale, cropping and interruption can carry ENCOUNTER while MEASURE's honesty discipline (dated facts, visible status, no invented cadence) keeps running underneath every beat.

No photographs in this study. Real venue/event photography exists in the legacy production site's upload assets, but those are professionally-lit, generic-hospitality-bar imagery (backlit bottle walls, artificial greenery, string lights) — exactly the bar-reduction/hospitality-cliché risk the direction warns against — and reusing them would also smuggle legacy-site material back in as design authority, which the greenfield rule forbids. The owner-supplied book PDF was reviewed for the sibling-relationship test but is not copied into this repository. So every image slot below is an honestly-labelled placeholder (a textured box, never a photograph, never a fake-photo filter) carrying only what production images would carry: a kind-marker, a date where relevant, and a real caption. What is under test is composition — scale, crop, density, proximity, interruption — not pixel content. This mirrors the direction's own honesty discipline: an unknown fact is shown as unknown; a missing photograph is shown as missing, not faked.
